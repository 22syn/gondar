# Files that MUST stay byte-identical between `main` (Smart Radar) and
# `stable` (Lean Radar).
#
# Why this file exists: the two radars run from two branches and each carries its
# own copy of the shared layer. A fix applied to one silently does not reach the
# other. That is not hypothetical — PR #49 migrated SMA/RSI to `trading-signals`
# on `main` only, and `stable` kept the hand-rolled version unnoticed for two
# months. Decision 2026-07-26 (see cabinet decisions-log): keep the two-branch
# split, but make the drift loud instead of silent.
#
# Checked by scripts/check-branch-drift.sh (CI: branch-drift.yml).
#
# INTENTIONALLY DIVERGING a file? Delete its line and say why in the commit
# message. Removing a line is the supported escape hatch — do not weaken the
# check itself.
#
# Not listed here (deliberately): files that legitimately differ because the two
# radars have different feature sets — config/index.ts, index.ts, llmSummary.ts,
# marketData.ts, telegramBot.ts, types/index.ts, championScore.ts, setup.ts,
# snapshotWriter.ts — plus everything that exists on only
# one branch (the fragility/OOS/D1-ingest layer on main, the lean/ modules on
# stable).
